# 🧬 EeveeZone // Projeto Final Autoria Web

> **Um centro de informações e comunidade para fãs de Pokémon, reunindo regiões, jogos, produtos temáticos e ferramentas interativas em um único lugar.**

O **EeveeZone** é um site estático desenvolvido utilizando **HTML5, CSS3 e JavaScript**, criado para reunir conteúdos sobre o universo Pokémon de forma organizada e interativa.

O projeto apresenta páginas dedicadas às principais regiões da franquia, uma loja temática inspirada no **PokéCenter**, uma ferramenta para criação de **Cards de Treinador** personalizados e uma seção contendo informações sobre alguns dos jogos mais importantes da série.

---

# ✨ Funcionalidades

- 🗺️ Informações completas sobre as regiões Pokémon
- 🎮 Página dedicada aos principais jogos da franquia
- 🛒 Loja temática (PokéCenter)
- 🃏 Criação de Card de Treinador personalizado
- 👥 Montagem de equipe com até seis Pokémon
- 🖼️ Galeria de imagens dos jogos
- 🎠 Carrosséis interativos desenvolvidos em JavaScript
- 📱 Layout responsivo para desktop, tablets e smartphones

---

# 🌎 Regiões Disponíveis

O site possui páginas exclusivas para cada uma das principais regiões da franquia Pokémon:

- Kanto
- Johto
- Hoenn
- Sinnoh
- Unova
- Kalos
- Alola
- Galar
- Paldea

Cada página apresenta informações como:

- história da região;
- Pokémon iniciais;
- treinadores marcantes;
- curiosidades;
- imagens ilustrativas.

---

# 🛒 PokéCenter

A seção **PokéCenter** simula uma loja virtual com diversos produtos inspirados em Pokémon.

Entre eles:

- Pelúcias
- Mochilas
- Canecas
- Chaveiros
- Colares
- Anéis
- Pins
- Skates
- Travesseiros
- Figures
- Meias

Cada produto possui uma página própria contendo imagens e informações.

---

# 🃏 Card do Treinador

Uma das principais funcionalidades do projeto é o sistema de criação de **Card de Treinador Pokémon**.

O usuário pode:

- escolher um avatar;
- informar seu nome;
- selecionar sua região;
- inserir uma descrição;
- montar um time com até **6 Pokémon**.

Os ícones do treinador são alterados dinamicamente utilizando JavaScript, tornando a experiência mais interativa. 

---

# 🎮 Jogos Pokémon

A seção de jogos reúne informações sobre diversos títulos da franquia, incluindo:

- Pokémon Red & Blue
- Pokémon Emerald
- Pokémon X & Y
- Pokémon Scarlet & Violet
- Pokémon GO

Os carrosséis de imagens são controlados por JavaScript, permitindo navegar entre diferentes capturas de tela. 

---

# 🎨 Interface

O projeto foi desenvolvido priorizando uma navegação intuitiva e agradável.

Entre os destaques da interface estão:

- menu de navegação presente em todas as páginas;
- identidade visual inspirada no universo Pokémon;
- temas personalizados para diferentes regiões;
- imagens organizadas por categorias;
- adaptação para diferentes tamanhos de tela através de Media Queries.

# 🎯 Objetivos

Este projeto foi desenvolvido com o objetivo de:

- praticar desenvolvimento web utilizando HTML, CSS e JavaScript;
