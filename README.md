# Eeveezone
Projeto final de autoria web
***
O website deverá atender aos seguintes critérios:
* Estrutura de layout bem definida e utilização dos contêineres semânticos;
* Construção de formulário com pelo menos quatro entradas;
* Menu de navegação;
* Possuir, no mínimo, 6 páginas;
* Ser responsivo;
